## Network Ninja
A network troubleshooting game for engineers. Take tickets from small businesses in the mountains of rural Japan, investigate with a Junos-style CLI, fix the fault in as few config lines as you can, and file the real root cause. Do something clever and Kage, the ninja, drops in.

**Play:** https://sigurd-41.github.io/Ninja-Space/network-ninja/

Runs entirely in the browser, single file at [`network-ninja/index.html`](network-ninja/index.html). Progress is saved in your browser. (The old `root-cause/` link redirects here.)

## Root Cause
A network troubleshooting game for engineers. Take tickets, investigate with a Junos-style CLI, fix the fault in as few config lines as you can, and file the real root cause.

**Play:** https://sigurd-41.github.io/Ninja-Space/root-cause/

Runs entirely in the browser, single file at [`root-cause/index.html`](root-cause/index.html). Progress is saved in your browser.
